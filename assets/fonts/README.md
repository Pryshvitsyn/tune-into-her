# Linux Libertine O Regular

Unmodified `LinLibertine_R.otf` extracted from the documented CTAN Libertine5.3.0 package:
https://ctan.org/texarchive/fonts/libertine
https://mirrors.ctan.org/fonts/libertine.zip

Font metadata: family `Linux Libertine O`, style `Regular`, PostScript `LinLibertineO`, version5.3.0, author Philipp H. Poll. SHA256:
`6332761e4fc08e30bce6f47e4a08e7d5332abe000ab6ca06c8e86bd88f456114`.
Only the asset filename and Expo runtime alias differ; font bytes and logo geometry are unchanged.

The archive's `LICENCE.txt` explicitly grants GPL with font exception and Open Font License; it refers to an OFL file omitted from that archive. We preserve its original statement and embedded font copyright/author metadata, and include the official SIL OFL1.1 text from https://openfontlicense.org/documents/OFL.txt with the placeholder example header removed. No reserved-name assertion was invented. This unmodified font is bundled under its OFL option.

The runtime alias is `LinuxLibertineO`; Expo Font must resolve it before onboarding is revealed. Hindi (`hi`) and Simplified Chinese (`zh-Hans`) deliberately use native system fonts because this font lacks those writing systems. Native-language typographic review remains necessary.
