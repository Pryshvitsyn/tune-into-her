## Scope and isolation

The run uses the existing daily selector and synthetic demo profile only. It does not
change the device clock, real cycle settings, personal history, normal reminders, or
purchase entitlement. The dev-only **Next test day** control changes only the
in-memory synthetic day display and is unavailable outside `__DEV__` with the
accelerated-demo flag.
