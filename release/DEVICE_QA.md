# Native release QA — record device, OS, build and result

Not performed by HTML preview or JavaScript bundling.

- Fresh install: onboarding languages, consent required, date picker, cycle ranges, daily preview, purchase, optional reminder.
- Small phone, large font and screen reader: every control reachable, no clipped content. Check Hindi, Chinese, long German/French labels.
- All 11 languages: interface, daily cue, settings, paywall, errors, notification; Baba Malay reviewed by community speaker.
- Consent declined: no cycle data accepted before acknowledgement. Update only voluntarily shared information.
- Purchases: eligible/ineligible trial, store cancellation, purchase error, offline store, restore, renewal, expiration, grace/billing retry, same-store reinstall.
- Notifications: no cycle day/context on lock screen, one per date, deny permission, change language/time/timezone, DST, app resume, delete data cancels reminders.
- Day rollover: keep Today open across midnight and resume after days away; daily cue refreshes.
- Delete local data: cycle secure storage, preferences and selection history removed; onboarding returns. Store subscription remains manageable separately.
- Links: support email monitored; legal HTTPS URLs public and live; paywall Terms does not open medical disclaimer.
- Privacy: inspect actual RevenueCat SDK traffic and declarations; cycle values never sent as attributes. Android backups disabled. Check iOS reinstall/keychain behavior.
- Assets: icon/adaptive icon legible on home screen; approved sphere confirmed against owner’s missing V4 reference.
- Capture real iPhone/Android screenshots with non-personal sample data, including subscription disclosure where relevant.
